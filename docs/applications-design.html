Why tabs inside Applications

Separate sidebar tabs (today)

Three menu items for one idea, three different-looking pages, and you search for a person in three places.

Tabs inside Applications (this design)

One menu item, one look. Summary cards on top, then clear lender tabs that switch the table. Same columns and filters for all three; each lender keeps its own status words and extras (Revasure's sheet upload).

One single table

The same person shows up to three times (6,482 rows for about 1,350 people), and each lender's statuses mean different things, so one status filter would mislead.
